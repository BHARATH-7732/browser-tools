# Data Scraping Tools

A professional, responsive website for the included Chrome extension downloads.

## Visual theme
- Deep charcoal background with red, orange, and white accents
- Subtle warm-colored particle background
- Smooth, restrained hover transitions
- Clear typography and simple layout

## Run locally
Extract the ZIP and open `index.html` in a browser.

## Publish
Upload the complete folder, including `images/` and `downloads/`, to any static website host.

## Features
- Responsive layout
- Subtle particle background
- Search across all included tools (press `/` to focus; `Esc` to clear)
- Reduced-motion support
- Original extension ZIP files and download paths preserved
